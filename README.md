# Декабристский жребий

Игра проекта «История и котики» по теме «Движение декабристов» (1812–1826).

- 3 судьбы: Офицер 1812 года, Член Южного общества, Литератор-северянин.
- По 10 испытаний в каждой: один ответ, несколько ответов, хронология, соответствие.
- 2 попытки на испытание, после первой ошибки — подсказка и страница учебника.
- Три неуспеха — арест. Успел пройти до ареста 3 испытания и больше — ссылка в Сибирь, меньше — тайная казнь.
- Всё в одном файле `index.html`, без сборки.

## Как выложить на GitHub Pages

1. В аккаунте historyandcats создай репозиторий `dekabristy` (Public).
2. Add file → Upload files → загрузи `index.html` и `README.md` → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты игра откроется по адресу https://historyandcats.github.io/dekabristy/
